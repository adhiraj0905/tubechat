#  TubeChat

 TubeChat is a web application that allows you to "chat" with any YouTube video

---

## 🧠 Overview
**TubeChat** transforms YouTube videos into interactive conversations. Paste a video link, and the AI extracts the transcript and answers your questions — summaries, explanations, or insights — all in real time.
